# SIGEDOR - Sistema de Gestión Docente

Sistema de Gestión Docente desarrollado con Laravel 11 y Filament 3.

## Documentación

Toda la documentación del proyecto se encuentra en el directorio [docs](./docs).

## Requisitos del Sistema

- PHP >= 8.2
- Composer
- Node.js y NPM
- MariaDB/MySQL

## Instalación

Las instrucciones de instalación están disponibles en la [documentación](./docs/requirements.md).
